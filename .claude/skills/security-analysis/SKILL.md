# Security Analysis Skill

Expert in application security, OWASP Top 10 vulnerabilities, and secure coding practices.

## OWASP Top 10
- Check for broken access control and unauthorized actions
- Check for cryptographic failures and insecure handling of sensitive data
- Check for injection vulnerabilities
- Check for insecure design patterns
- Check for security misconfiguration
- Check for vulnerable or outdated dependencies
- Check for authentication and identification weaknesses
- Check for software and data integrity issues
- Check for insufficient logging and monitoring
- Check for server-side request forgery risks

## Secure Coding Practices
- Validate and sanitize untrusted input
- Use parameterized queries instead of constructing queries from user input
- Protect authentication credentials, tokens, and secrets
- Apply least-privilege access
- Use secure defaults
- Avoid exposing sensitive information in errors or logs
- Validate data received from external systems
- Use appropriate security controls for file and network operations

## Common Security Mistakes
- Hardcoded passwords, API keys, and secrets
- Unsanitized user input
- Unsafe dynamic code execution
- Missing authorization checks
- Insecure direct object references
- Sensitive information exposed in logs or responses
- Weak or improper cryptographic practices
- Missing security validation at trust boundaries

## Output:
For each security issue provide:
1. Description
2. Security impact
3. Recommended fix
4. OWASP category when applicable
5. Severity level
